# agents

Tools, skills and other useful information for agents.

## The plugin

One plugin, one sign-in. Your brand follows from who signs in.

In a terminal:

```
claude plugin marketplace add clero-is/agents
claude plugin install clero@clero-agents
```

Or inside Claude Code: `/plugin install clero --marketplace clero-is/agents`

Then start Claude Code, type `/mcp`, pick `plugin:clero:brand`, choose Authenticate, and say yes in the browser.
